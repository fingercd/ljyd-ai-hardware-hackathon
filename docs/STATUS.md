## 已处理的环境问题
- 英文联接与真实路径的环境登记差异：本项目使用对应版本的明确工具路径。
- ccache 的 Unicode 路径异常：保持禁用，不改全局系统 UTF-8。
- idf.py 将 junction 解析为中文真实路径，导致 objcopy 输出失败：改用显式 CMake ASCII 源/输出路径。
- 组件元数据将预编译库路径还原为中文，导致最终链接失败：仅把生成的 Ninja/response 文件中的本工作区路径规范为已存在的英文入口，不改第三方源码和库。
- CMD AutoRun 重复激活科研 Conda：设置真实 SDK VIRTUAL_ENV 标记，未改注册表或全局 Conda。单次子 shell 测量由 3.416 秒降至 0.307 秒，不能把这个数直接当作完整构建加速比。

失败尝试和最终日志均保存在本机忽略目录，公开文档只给脱敏摘要。
