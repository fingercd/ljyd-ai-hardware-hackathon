# 接板与首次联调

当前未完成实物核验。本页是待执行清单，不代表设备已验证。

## 先确认再上电

1. 核对主板和语音板丝印、版本、USB 用途，以及是否与厂商手册的 XJWB03-DevKIT-V1 / LJX40-Audio-KIT-V1 对应。
2. 断电连接配套语音板排线和喇叭，确认方向，不硬插。只用符合板卡标注的供电和支持数据的 USB 线。
3. 首次只接主板、语音板与喇叭；摄像头、MPU6050、灯带、舵机和马达后续逐项接入。
4. 不把 ESP32-S3 的芯片型号当作板级接线依据；GPIO、电压和接口以实物及对应版本资料为准。

## 连接电脑后

- 枚举 COM，和插入前的状态比较；不要把已有蓝牙串口误当成板卡。
- 明确目标后查看启动日志。对应手册的 UART0 为 115200、8N1；打开串口也可能改变复位控制线。
- 记录提示音、启动过程、是否反复重启、是否等待配网；日志先保存在本机并注意凭据脱敏。
- 在核对原固件、产品身份和必要备份前，不直接刷入仓库示例。

## 再决定刷写与联网

- 确认芯片/Flash 容量、构建目标、分区和全部镜像清单。
- 区分只刷应用、全镜像与整片擦除；首次覆盖现状按实际范围决定备份，备份中可能包含敏感 NVS 数据。
- 创建或关联自己的产品/Agent，核对 PID、密钥和平台环境。示例身份不等于自己的产品。
- 按厂商当前小程序流程配置 2.4 GHz Wi-Fi，核对实际在线状态及 `cloud connected`，再测试语音。
- 验收至少包括连续对话、重启重连，以及一项与场景有关的真实任务；网页预览成功不能替代这些结果。

GPIO14 的长按可能触发解绑或清配网，不当作普通检测步骤。eFuse、Secure Boot、Flash Encryption 及永久禁用调试/下载不属于基础上手操作。
