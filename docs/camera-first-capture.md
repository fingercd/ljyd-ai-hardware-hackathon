## 命令行拍照

当前诊断固件不是串口命令解释器，没有可以直接输入的 `capture`/`photo` 固件指令。以下电脑端命令先打开接收，再普通RTS复位一次，接收启动后的单帧，校验后在电脑保存PNG；不烧录、不擦除，也不操作BOOT。

Windows PowerShell：

```powershell
Set-Location 'D:\PythonProject\AI硬件'
.\scripts\camera.cmd --list
.\scripts\camera.cmd --port COM3
```

若只有一个USB标识1A86:55D3的板子，也可直接执行 `.\scripts\camera.cmd` 自动选端口。`--list`只枚举，不打开或复位。每运行一次拍一张，等待几十秒；Ctrl+C取消电脑接收，不等同立即中断板端输出。请先关闭其他占用该串口的监视器，不要多人同时控制。

成功后输出完整PNG路径，图像保存在 `artifacts/camera-photo-时间戳/camera-native.png`，原始YUV、元数据与串口日志保留在本地忽略目录，不上传云端/公开Git。串口失败或180秒未收齐会报错退出，不自动重试或重新烧录。开串口也可能有控制线瞬态，不声称完全无复位影响。

入口和接收/校验/PNG编码通过离线单元测试，串口枚举已在本机验证；该新入口尚未另做一次实板拍照，不能拿历史手工采集替代新入口端到端验收。

## 本机网页拍照与低帧率录像

在 PowerShell 中启动（不需要刷写固件）：

```powershell
Set-Location 'D:\PythonProject\AI硬件'
.\scripts\camera-web.cmd
```

程序会打开本机网页，也会在终端输出带访问凭证的地址。不要向他人分享这个地址。点击“拍照”下载经过长度和 FNV 校验的真实 PNG；点击“开始低帧率录像”，先等第一帧，再逐帧采集；点击停止后等待当前帧完成，浏览器下载无声音视频。采集失败会停止录像并尽可能保存已有片段。浏览器需支持 MediaRecorder 和 canvas.captureStream，建议 Chrome 或 Edge。照片和视频保存在浏览器下载目录，不自动上传。

**重要限制：**现在的相机诊断固件只在启动时输出一帧，每帧都要普通复位一次，单帧可能几十秒；录像只是在相邻真实帧之间保持旧画面，并非实时或流畅视频。录制时间包含等待时间，停止不会立即中断正在进行的接收（超时上限180秒）；启动或使用网页不会烧录固件。请勿同时打开串口监视器。断开设备或占用串口会显示错误。停止网页服务使用终端 Ctrl+C。

本网页接口已通过模拟成功、设备错误、并发与访问保护测试；由于当前未枚举到板卡，尚未完成网页端真实拍照、录像及浏览器播放的实板验收。连续复位的可靠性及成像质量也未验证。
